# Schrift

Outfit (variable Schrift, Gewichtsachse 100–900), SIL Open Font License 1.1.
Quelle: https://github.com/google/fonts/tree/main/ofl/outfit

`Outfit.ttf` und die zugehörige `OFL.txt` werden lokal mitgeliefert.
Die Schrift wird ausschließlich beim Rendern benötigt.

Spielgrafiken werden aus `client/public/assets/` des Projekts wiederverwendet.
